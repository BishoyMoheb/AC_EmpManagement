# AC_EmpManagement
It is a C# .NET Core solution that uses models and view models along with Entity Framework Core for the migration  of classes to tables in the Database.

The solution gives a public page for list of employees and sets the modification of data for login user. The logged in user is classified according to one of the following roles (Super Admin Role, Admin Role, General Role, Test Role) and each role has its claims.

The solution contains 4 controllers to manage the Login, Admin, Employee, Error management.

The login can be done using the default way after registering a new user or by using External Login with Google or Facebook.

The solution contains *.cshtml file for multiple situation for case study.
